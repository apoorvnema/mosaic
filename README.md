# Mosaic

One notebook that stops making you choose: instant capture, notebooks and desktop
stickies, typed databases, plain markdown files, and an infinite canvas — local-first,
on files you own.

**Status:** skeleton. Structure, interfaces, tooling and tests are in place; product
features are built session by session. See [docs/ROADMAP.md](docs/ROADMAP.md).

```bash
pnpm install
pnpm dev        # web app at http://localhost:5173, running against ./dev-vault
pnpm verify     # lint + typecheck + test
```
